# Assets Directory

Esta pasta contém as imagens do portfólio. Para adicionar suas próprias imagens:

## Foto de Perfil
- Nome do arquivo: `profile-photo.jpg`
- Dimensões recomendadas: 400x400px (quadrada)
- Formato: JPG ou PNG

## Imagens dos Projetos
- `dashboard-comercial.jpg` - Screenshot do dashboard comercial
- `dashboard-logistica.jpg` - Screenshot do dashboard de logística  
- `dashboard-financeiro.jpg` - Screenshot do dashboard financeiro
- `dashboard-vendas.jpg` - Screenshot do dashboard de vendas
- `dashboard-rh.jpg` - Screenshot do dashboard de RH
- `dashboard-marketing.jpg` - Screenshot do dashboard de marketing

### Especificações das imagens dos projetos:
- Dimensões recomendadas: 800x600px (4:3)
- Formato: JPG ou PNG
- Qualidade: Alta resolução para melhor visualização

## Como adicionar as imagens:
1. Salve suas imagens nesta pasta (`public/assets/`)
2. Use os nomes de arquivo exatos listados acima
3. As imagens aparecerão automaticamente no site

## Fallback:
Se alguma imagem não for encontrada, o sistema mostrará um placeholder com gradiente colorido.
